# Dungeon Logic — Solver v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a deterministic pure-TypeScript puzzle solver that counts `0 / 1 / 2+` WALL/OPEN solutions for a `LevelDefinition`, returns the first solution, and stops immediately after the second accepted solution.

**Architecture:** Solver state is separate from runtime `PuzzleState` because runtime `UNKNOWN` already means OPEN. `SearchState` owns the tri-state partial assignment and reversible search data; `PuzzleSolver` performs propagation, safe pruning, deterministic DFS, and materializes complete candidates into the existing `PuzzleState` so `LevelValidator` remains the final source of truth.

**Tech Stack:** TypeScript, Vite, existing Dungeon Logic puzzle core. No Phaser dependency inside `src/puzzle/solver/`.

**Spec:** `docs/superpowers/specs/2026-09-02-solver-v1-design.md`

## Global Constraints

- Public API is `solveLevel(level: LevelDefinition): SolveResult`.
- `SolveResult.solutionCount` is exactly `0 | 1 | 2`; `2` means `2+`.
- `firstSolution` is `null` only when there is no solution.
- Search uniqueness is based only on final ordinary-cell `WALL / OPEN` layout.
- `LevelValidator` is the final authority for every complete candidate.
- `level.solution` must never be read by solver code.
- Monster, Chest, and Directional Door are fixed OPEN.
- Fixed Blocker is CLOSED metadata, never clue-counted WALL.
- Door framing cells must be ordinary `CellState.Wall`; Blocker cannot substitute.
- Search order is deterministic.
- Branch order is `WALL` then `OPEN`.
- Search stops immediately after accepting the second solution.
- Target boards are ordinary levels up to 10×10.
- ~1 second is a profiling target, not an automated timing assertion.
- No TypeScript enums; `erasableSyntaxOnly` remains enabled.
- No solver UI, hints, generator, SAT/SMT, randomness, or gameplay-state solving.
- Run `npm run build` at every implementation checkpoint.
- Run local dev sanity checks after every solver behavior change.
- Commit every independently testable task.
- After every commit run `npm run context:last`.
- Keep git commands PowerShell/cmd-safe; do not use Unix backslash continuations.

```ts
import type {
  GridPosition,
  LevelDefinition,
} from '../types';

import {
  SearchCellState,
  type SearchCellStateValue,
} from './types';

interface TrailEntry {
  x: number;
  y: number;
  previous: SearchCellStateValue;
}

export class SearchState {
  readonly level: LevelDefinition;

  private readonly cells:
    (
      SearchCellStateValue |
      null
    )[][];

  private readonly fixedOpen =
    new Set<string>();

  private readonly trail:
    TrailEntry[] = [];

  constructor(level: LevelDefinition) {
    this.level = level;

    this.cells = Array.from(
      { length: level.height },
      () =>
        Array<SearchCellStateValue | null>(
          level.width,
        ).fill(
          SearchCellState.Unassigned,
        ),
    );

    for (const blocker of level.blockers) {
      this.cells[blocker.y][blocker.x] =
        null;
    }

    for (
      const position
      of [
        ...level.monsters,
        ...level.chests,
        ...level.doors.map(
          (door) => door.position,
        ),
      ]
    ) {
      const key =
        this.positionKey(position);

      this.fixedOpen.add(key);

      this.cells[position.y][position.x] =
        SearchCellState.Open;
    }
  }

  getCellState(
    x: number,
    y: number,
  ): SearchCellStateValue | null {
    return this.cells[y][x];
  }

  isMutableCell(
    x: number,
    y: number,
  ): boolean {
    if (this.cells[y][x] === null) {
      return false;
    }

    return !this.fixedOpen.has(
      `${x}:${y}`,
    );
  }

  assign(
    x: number,
    y: number,
    next: SearchCellStateValue,
  ): boolean {
    if (
      next ===
      SearchCellState.Unassigned
    ) {
      throw new Error(
        'SearchState.assign cannot assign UNASSIGNED.',
      );
    }

    const current =
      this.cells[y][x];

    if (current === null) {
      return false;
    }

    if (current === next) {
      return true;
    }

    if (
      current !==
      SearchCellState.Unassigned
    ) {
      return false;
    }

    if (!this.isMutableCell(x, y)) {
      return false;
    }

    this.trail.push({
      x,
      y,
      previous: current,
    });

    this.cells[y][x] = next;

    return true;
  }

  checkpoint(): number {
    return this.trail.length;
  }

  rollback(
    checkpoint: number,
  ): void {
    while (
      this.trail.length >
      checkpoint
    ) {
      const entry =
        this.trail.pop();

      if (entry === undefined) {
        throw new Error(
          'SearchState trail underflow.',
        );
      }

      this.cells[entry.y][entry.x] =
        entry.previous;
    }
  }

  isComplete(): boolean {
    return (
      this.getUnassignedMutablePositions()
        .length === 0
    );
  }

  getUnassignedMutablePositions():
    readonly GridPosition[] {
    const result: GridPosition[] = [];

    for (
      let y = 0;
      y < this.level.height;
      y += 1
    ) {
      for (
        let x = 0;
        x < this.level.width;
        x += 1
      ) {
        if (
          this.isMutableCell(x, y) &&
          this.cells[y][x] ===
            SearchCellState.Unassigned
        ) {
          result.push({ x, y });
        }
      }
    }

    return result;
  }

  private positionKey(
    position: GridPosition,
  ): string {
    return (
      `${position.x}:${position.y}`
    );
  }
}
```

Add deterministic DFS:

```ts
function search(
  state: SearchState,
  context: SearchContext,
): void {
  if (context.solutionCount === 2) {
    return;
  }

  const checkpoint =
    state.checkpoint();

  const propagated =
    propagateLineConstraints(state);

  if (
    !propagated ||
    !areLineConstraintsFeasible(state)
  ) {
    state.rollback(checkpoint);
    return;
  }

  if (state.isComplete()) {
    acceptCompleteCandidate(
      state,
      context,
    );

    state.rollback(checkpoint);
    return;
  }

  const next =
    state
      .getUnassignedMutablePositions()[0];

  if (next === undefined) {
    state.rollback(checkpoint);
    return;
  }

  branch(
    state,
    context,
    next,
    SearchCellState.Wall,
  );

  if (context.solutionCount < 2) {
    branch(
      state,
      context,
      next,
      SearchCellState.Open,
    );
  }

  state.rollback(checkpoint);
}
```

```ts
function propagateLineConstraints(
  state: SearchState,
): boolean {
  let changed = true;

  while (changed) {
    changed = false;

    for (
      let y = 0;
      y < state.level.height;
      y += 1
    ) {
      const result =
        propagateLine(
          state,
          state.getRowStatus(y),
        );

      if (!result.valid) {
        return false;
      }

      changed =
        changed ||
        result.changed;
    }

    for (
      let x = 0;
      x < state.level.width;
      x += 1
    ) {
      const result =
        propagateLine(
          state,
          state.getColumnStatus(x),
        );

      if (!result.valid) {
        return false;
      }

      changed =
        changed ||
        result.changed;
    }
  }

  return true;
}

function propagateLine(
  state: SearchState,
  status: LineStatus,
): {
  valid: boolean;
  changed: boolean;
} {
  if (!isLineFeasible(status)) {
    return {
      valid: false,
      changed: false,
    };
  }

  const wallsNeeded =
    status.target -
    status.wallsPlaced;

  let changed = false;

  if (wallsNeeded === 0) {
    for (
      const position
      of status.unassigned
    ) {
      if (
        !state.assign(
          position.x,
          position.y,
          SearchCellState.Open,
        )
      ) {
        return {
          valid: false,
          changed,
        };
      }

      changed = true;
    }
  } else if (
    wallsNeeded ===
    status.unassigned.length
  ) {
    for (
      const position
      of status.unassigned
    ) {
      if (
        !state.assign(
          position.x,
          position.y,
          SearchCellState.Wall,
        )
      ) {
        return {
```

```ts
isPotentialConnectivityValid():
  boolean {
  const mandatoryOpen:
    GridPosition[] = [];

  for (
    let y = 0;
    y < this.level.height;
    y += 1
  ) {
    for (
      let x = 0;
      x < this.level.width;
      x += 1
    ) {
      if (
        this.cells[y][x] ===
        SearchCellState.Open
      ) {
        mandatoryOpen.push({
          x,
          y,
        });
      }
    }
  }

  if (mandatoryOpen.length <= 1) {
    return true;
  }

  const start =
    mandatoryOpen[0];

  const queue:
    GridPosition[] = [start];

  const visited =
    new Set<string>();

  while (queue.length > 0) {
    const current =
      queue.shift();

    if (current === undefined) {
      break;
    }

    const key =
      `${current.x}:${current.y}`;

    if (visited.has(key)) {
      continue;
    }

    visited.add(key);

    const neighbors =
      [
        {
          x: current.x + 1,
          y: current.y,
        },
        {
          x: current.x - 1,
          y: current.y,
        },
        {
          x: current.x,
          y: current.y + 1,
        },
        {
          x: current.x,
          y: current.y - 1,
        },
      ];

    for (
      const neighbor
      of neighbors
    ) {
      if (
        neighbor.x < 0 ||
        neighbor.x >=
          this.level.width ||
        neighbor.y < 0 ||
        neighbor.y >=
          this.level.height
      ) {
        continue;
      }

      const cell =
        this.cells[
          neighbor.y
        ][neighbor.x];

      if (
        cell === null ||
        cell ===
          SearchCellState.Wall
      ) {
        continue;
      }

      const neighborKey =
        `${neighbor.x}:${neighbor.y}`;

      if (
        !visited.has(
          neighborKey,
        )
      ) {
        queue.push(neighbor);
      }
    }
  }

  return mandatoryOpen.every(
    (position) =>
      visited.has(
        `${position.x}:${position.y}`,
      ),
  );
}
```

- `UNASSIGNED` is traversable;
- only blocker/null and assigned WALL are closed;
- partial state does not need to be connected yet;

```ts
    this.roomCandidatePressure(
      position,
    );

  return (
    rowScore +
    columnScore +
    doorScore +
    roomScore
  );
}

private lineConstraintScore(
  status: LineStatus,
): number {
  const remaining =
    status.unassigned.length;

  if (remaining === 0) {
    return 0;
  }

  const wallsNeeded =
    status.target -
    status.wallsPlaced;

  const openNeeded =
    remaining -
    wallsNeeded;

  const slack =
    Math.min(
      wallsNeeded,
      openNeeded,
    );

  return 100 - slack;
}

private roomCandidatePressure(
  position: GridPosition,
): number {
  let pressure = 0;

  for (
    const candidates
    of this.roomCandidates.values()
  ) {
    const viable =
      candidates.filter(
        (candidate) =>
          candidate.cells.every(
            (cell) =>
              this.cells[
                cell.y
              ][cell.x] !==
                SearchCellState.Wall,
          ),
      );

    if (
      viable.some(
        (candidate) =>
          candidate.cells.some(
            (cell) =>
              cell.x ===
                position.x &&
              cell.y ===
                position.y,
          ),
      )
    ) {
      pressure +=
        Math.max(
          1,
          20 - viable.length,
        );
    }
  }

  return pressure;
}
```

The exact score is only a deterministic search heuristic. It must never decide validity.
