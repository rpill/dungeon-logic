# Daily v1 Calendar Binding

**Release-candidate anchor:** `2026-09-09` UTC  
**Last bound day:** `2027-09-08` UTC  
**Entries: 365 consecutive days**

The shipped Daily schedule binds the static `daily-001` … `daily-365` snapshots to trusted UTC dates. Runtime selection reads only this static mapping and never generates a puzzle on the player device.

The original bindings `daily-001` … `daily-060` (`2026-09-09` … `2026-11-07`) are preserved unchanged. The extension adds `daily-061` … `daily-365` through `2027-09-08`. Once a dated Daily has shipped, that published date→snapshot mapping is treated as immutable; a later game update may replace only future, not-yet-released Daily content.
